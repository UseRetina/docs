Retina is in password-gated private beta.

## Request the password

DM [@UseRetina](https://x.com/UseRetina) on X. You will receive a password.

## What the password unlocks

Entering the password at [useretina.xyz](https://useretina.xyz) unlocks the app on the current browser and device. The unlock persists until you clear site data for the domain.

<Note>
The password unlocks the app, nothing else. There is no account behind it. The same password used on a different browser or device requires unlocking again on that browser or device.
</Note>

<Warning>
Clearing site data for `useretina.xyz` removes the unlock and deletes every snapshot, wallet, and manual position stored locally. Export from the [Positions](/pages/positions) page first if you want to keep that data.
</Warning>
