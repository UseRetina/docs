---

The History page is where the snapshot model pays off. Every snapshot you have created is on this page, compared against the others.

## Summary cards

- **Latest Saved Value**
- **Net Change** (across the full timeline)
- **Timeline**: snapshot count
- **Average per Day**
- **Best Snapshot Change**
- **Worst Snapshot Change**
- **Latest Polymarket value**
- **Latest Locked Capital %**

## Charts

- **Portfolio Value over time**: line chart with toggleable layers for Total, Positions, Polymarket, Metals
- **Latest Asset Split**: pie for the most recent snapshot
- **Asset Mix Over Time**: stacked area showing how the asset split evolved across snapshots
- **Change by Snapshot**: bar chart of the delta between each consecutive pair of snapshots

## Snapshot Ledger

A table with 1 row per snapshot:

- Date
- Total
- Change vs the previous snapshot
- Asset split
- Polymarket value
- Metals value
- Locked %
- Position count
- Wallet count
- Top protocol
- **Open** / **Delete** buttons

<Warning>
**Delete** removes the snapshot from local storage. There is no undo.
</Warning>
