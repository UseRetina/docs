The Protocols page is the protocol-level view of the active snapshot. Each protocol is a card.

## Card contents

- Protocol name
- Total value across all your positions in this protocol
- Position count
- Asset types present (Spot / Wallet, Staking, Locked, LP Position, Yield Vault, Deposit / CEX, Reward; see [Position types](/concepts/position-types))
- Weighted APY
- Estimated daily income

## Filters

Asset filter chips at the top filter cards by [asset class](/concepts/asset-classes):

- **Alt**
- **BTC**
- **ETH**
- **HYPE**
- **USD**

## Sort

Sort options:

- Value
- Positions
- Asset types
- APY
