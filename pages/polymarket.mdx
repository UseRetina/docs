The Polymarket page shows open prediction market positions for every wallet you flagged in [setup](/getting-started/quickstart) (either via **Use for Polymarket** in step 1 or as a dedicated Polymarket wallet in step 3).

Polymarket data is live. The page calls Polymarket's public API directly when you load it, so the values reflect current market prices, not the active snapshot's prices.

## Header cards

- **pUSD cash balance**: total Polymarket USD balance across your Polymarket wallets.
- **Open position value**: current value of every open position.

## Per-wallet cards

Each Polymarket wallet appears as a card with:

- Total pUSD cash
- Position count
- Open P&L

## Positions table

For each open position:

| Column | What it shows |
| --- | --- |
| Market | The market question |
| Side | Yes or No |
| Ends | Market resolution date |
| Days | Days until resolution |
| Win APR | Implied return if the position resolves in your favor |
| Shares | Number of shares held |
| Avg entry | Average entry price per share |
| Current price | Current market price per share |
| Value | `shares × current price` |
| P&L | Absolute profit or loss |
| P&L% | P&L as a percent of entry |
