The Polymarket view follows every Polymarket address in your portfolio.

## Live and saved modes

When the latest snapshot is active, Retina can refresh public Polymarket information so you see current market data. When an older snapshot is active, the page uses the Polymarket state saved with that snapshot.

The page labels the mode and shows freshness or provider warnings when needed.

## Portfolio view

Use the summary and tabs to inspect:

- pUSD cash
- Current open-position value
- Profit or loss over time
- Open and closed positions
- Per-wallet totals
- Polymarket activity

Each position can include the market, side, shares, average entry, current price, value, end date, and profit or loss where public data provides it.

## Wallet details

Open a Polymarket wallet to see its positions and activity separately. Use **Manage wallets** to add, relabel, or remove tracked Polymarket addresses before a future snapshot.

## Public API limits

Retina reads public wallet and market data. Open orders are not available through the public wallet APIs Retina uses, so they are not included in the portfolio total.

Retina never places, closes, or signs a Polymarket order.
