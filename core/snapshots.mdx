A snapshot is a saved view of your portfolio at a specific time. It is the main unit of history in Retina.

## What a snapshot contains

A snapshot can include:

- Positions from EVM and Solana wallets
- Hyperliquid positions associated with tracked addresses
- Polymarket balances and positions
- Manual positions and metals
- Prices, APYs, maturities, liquidity, and position classifications
- The tracked source configuration used for that capture

Older snapshots keep the values recorded at capture time. They do not change when prices or provider data change later.

## Create a snapshot

Select **+ Snapshot** from the app header.

- Use the quick capture to reuse saved sources.
- Edit sources when you want to add, remove, or relabel something first.

Retina checks snapshot access and account limits before starting. The app shows your current daily allowance and the next available capture time when a cooldown applies.

## Daily limits and retries

Focus includes 1 automatic and 1 manual snapshot allowance each day. Range and Horizon include 2 automatic and 1 manual allowance.

An automatic slot can become available for manual use when no automatic run remains due that day. This lets you turn automatic updates off and use the same capacity manually. Successful captures are kept at least 1 hour apart.

A failed provider pass does not save a snapshot or spend a successful capture slot. Retry the affected wallet or capture after Retina reports that the provider or account data allowance is ready.

## Review before saving

Retina checks whether required sources returned complete results and whether large changes can be explained.

For a manual capture, you may be asked to:

- Refresh an affected wallet
- Exclude an incorrect asset and recalculate
- Continue when you recognize the result as correct

Automatic captures use the same principle. A blocking finding becomes a candidate for review instead of entering history. An advisory finding can be saved with a visible flag.

## Select and manage snapshots

Use the snapshot selector at the top of the sidebar to change the active snapshot. Most app views follow that selection.

From snapshot management you can:

- Open a snapshot
- Rename it
- Delete it
- Export portfolio data
- Compare it with earlier snapshots in History

Deleting a synced snapshot also updates the account copy after the deletion is confirmed. Deletion does not restore a daily capture allowance that was already used.

## Live data inside snapshot views

Most totals come from the active snapshot. Some surfaces deliberately fetch newer public information, especially current Polymarket data and yield information. Retina labels these states so you can tell saved values from refreshed values.
