---
title: "Snapshots"
description: "Create, review, select, rename, and compare point-in-time copies of your Retina portfolio."
---

A snapshot is a saved view of your portfolio at a specific time. It is the main unit of history in Retina.

## What a snapshot contains

A snapshot can include:

- Positions from EVM and Solana wallets
- Hyperliquid positions associated with tracked addresses
- Polymarket balances and positions
- Manual positions and metals
- Prices, APYs, maturities, liquidity, and position classifications
- The tracked source configuration used for that capture

Older snapshots keep the values recorded at capture time. They do not change when prices or provider data change later.

## Create a snapshot

Select **+ Snapshot** from the app header.

- Use the quick capture to reuse saved sources.
- Edit sources when you want to add, remove, or relabel something first.

Retina checks snapshot access and account limits before starting. My Account, the **+ Snapshot** choice, setup, the capture reservation, and the final save all use the same current allowance from your account. The app shows the next available capture time when a cooldown applies.

## Daily limits and retries

Focus includes 1 automatic and 1 manual snapshot allowance each day. Range and Horizon include 2 automatic and 1 manual allowance.

An automatic slot can become available for manual use when no automatic run remains due that day. My Account includes that slot in the manual allowance for the rest of the day, and the snapshot flow uses the same effective total. Successful captures are kept at least 1 hour apart.

When a wallet cannot be read, Retina shows **No snapshot saved** and spends no capture slot. Select **Try again** after a few minutes. If the account's data allowance is used, it resets at midnight UTC.

Pendle positions have one exception. When Pendle cannot be reached, Retina can keep the value Pendle last gave a position for up to 48 hours from when Pendle priced it, as long as nothing in that position changed since: no deposit, withdrawal, transfer or other transaction touching it, and no Pendle position opened or closed in that wallet. The snapshot is saved, and the next snapshot Pendle answers brings the value up to date. Earned APY leaves those days out, so a reused value never counts as earnings.

## Review before saving

Retina checks whether required sources returned complete results and whether large changes can be explained.

For a manual capture, you may be asked to:

- Refresh an affected wallet
- Exclude an incorrect asset and recalculate
- Continue when you recognize the result as correct

A snapshot keeps the time your wallets were read, even when you continue some time later. If a newer snapshot was saved while it waited, create a new snapshot instead.

Automatic captures use the same principle. A blocking finding becomes an unsaved snapshot review instead of entering history. An advisory finding can be saved with a visible flag. Open **Updates** from the sidebar to review either state.

An automatic review compares the previous and proposed totals and shows the balances that caused the pause. For each balance, choose **Use this value** or **Check again**. You can confirm a known deposit while rechecking a different protocol or wallet balance. Retina targets only the wallets connected to the selected balance and keeps the complete snapshot unsaved until the remaining checks pass.

## Select and manage snapshots

Use the snapshot selector at the top of the sidebar to change the active snapshot. Most app views follow that selection.

From snapshot management you can:

- Open a snapshot
- Rename it
- Delete it
- Export portfolio data
- Compare it with earlier snapshots in History

Deleting a synced snapshot also updates the account copy after the deletion is confirmed. Deletion does not restore a daily capture allowance that was already used.

## Live data inside snapshot views

Most totals come from the active snapshot. Some surfaces deliberately fetch newer public information, especially current Polymarket data and yield information. Retina labels these states so you can tell saved values from refreshed values.
