---
title: "Cloud history and automatic updates"
description: "Understand account sync, multi-device restore, automatic snapshots, notifications, and review in Retina."
---

Retina keeps a browser working copy and a cloud account copy of a signed-in portfolio. New snapshots sync to the account so your history can be restored elsewhere.

Automatic portfolio updates are optional. Cloud history does not require you to turn on a schedule.

## Use Retina on another device

Sign in with a method linked to the same Retina account. When the browser has no existing portfolio, Retina restores the account's saved data automatically.

When the browser and account already contain different histories, Retina pauses before replacing anything. You can keep the browser version, download a backup, or use the account version.

## Turn on automatic updates

Open **My Account** and enable **Automatic portfolio updates**.

Choose:

- The capture time
- Your timezone
- A second daily slot when your account includes one
- Which email notifications you want to receive

The account panel shows the next planned run and today's automatic and manual snapshot use.

Automatic updates run without an open browser. They use the sources and portfolio settings saved with your account.

## Notifications

Email notifications can cover:

- Successful automatic updates
- Failed updates
- Updates waiting for review
- A weekly maturity summary

Turn off any notification category you do not want.

## Review protection

Retina does not add a partial automatic result to history. It rechecks temporary provider warnings once within the same automatic run before grading the result.

- A blocking finding waits for your review.
- An advisory finding is saved with its reason attached.
- Later automatic updates can continue while an older candidate remains available for review.

Open **My Account** when Retina reports that an update needs a quick check. You can retry the affected wallets, skip the candidate, or keep it when you know the values are correct.

## Snapshot allowances

The account panel shows your total address, daily capture, and retained-history limits.

| Plan | Total addresses | Automatic snapshots per day | Manual allowance per day | Retained snapshots |
| --- | ---: | ---: | ---: | ---: |
| Focus | 1 | 1 | 1 | 5,000 |
| Range | 5 | 2 | 1 | 5,000 |
| Horizon | 50 | 2 | 1 | 5,000 |

The address limit applies across EVM, Solana, and Polymarket sources together. An automatic slot becomes available for manual use when no automatic run can still use it that day. My Account moves that capacity into the Manual row and shows only the automatic capacity still scheduled for today. The **+ Snapshot** choice, setup, capture reservation, and final save use the same effective allowance. Retina keeps successful captures at least 1 hour apart.

Interactive wallet checks and automatic captures share a separate account data allowance. Retina applies it on the server before contacting a portfolio provider. A failed or interrupted pass has recovery headroom, while repeated checks cannot run without limit. The visible error states when this daily data allowance has been used.

## If sync is interrupted

Retina keeps the last durable browser copy. Open **My Account** to retry backup or resolve a version conflict. Download a full backup before choosing a replacement when you want an extra recovery copy.
