title: "Position types"
description: "Retina's 7 position types (Spot, Staking, Locked, LP, Yield Vault, Deposit/CEX, Reward) describe how a position is held, separate from its asset class."
---

A position type describes how you hold the position, not what it is exposed to. For economic exposure, see [Asset classes](/concepts/asset-classes). Every position has exactly 1 type.

## The types

| Type | What it is |
| --- | --- |
| **Spot / Wallet** | Tokens sitting in a wallet, not deposited anywhere |
| **Staking** | Native or liquid staking (stETH, wstETH, sHYPE, etc.) |
| **Locked** | A token-locked position with a fixed unlock date (Pendle PT, locked vault) |
| **LP Position** | Liquidity provided to an AMM or concentrated liquidity pool |
| **Yield Vault** | A deposit into an auto-compounding or curated vault |
| **Deposit / CEX** | A balance held on a centralized exchange or manual deposit account |
| **Reward** | An unclaimed reward token, accruing or claimable |
