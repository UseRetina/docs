Solana coverage is multi-provider because no single API covers Solana DeFi well.

## Providers

### Helius

Account balances and on-chain history. Helius is the primary RPC layer for Solana data.

### Jupiter

Token metadata and Solana DEX positions.

### Vybe Network

DeFi positions and protocol-level data for Solana.

### Moralis

Additional token and position data.

## How they combine

Retina queries the providers in parallel for each Solana wallet and merges the results into one normalized position list. Where providers disagree on value, the app falls back to the source most likely to be correct for that asset class.
