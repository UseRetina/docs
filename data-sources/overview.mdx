Retina has no backend database of your portfolio. When the app needs data, it calls public APIs directly from your browser and stores the result locally. Every page in the app is built on top of these providers.

## Providers by category

| Category | Providers |
| --- | --- |
| [Prices](/data-sources/prices) | CoinGecko, GoldApi |
| [EVM wallets and positions](/data-sources/evm) | Zerion |

| [Prediction markets](/data-sources/prediction-markets) | Polymarket |
| [Yield data](/data-sources/yield-data) | Pendle, DeFiLlama |

| [Airdrops and rewards](/data-sources/airdrops-and-rewards) | DropsBot, Merkl, Pendle |

## How requests are made

Most providers are queried directly from the browser. A few requests go through a thin Cloudflare Function proxy so the app does not have to ship third-party API keys. The proxy does not store your wallet addresses or your portfolio data.

## What happens if a provider is down

Retina fails gracefully per provider. If Pendle is rate-limited, the rest of the dashboard still loads, but Pendle-sourced APYs may be missing. Cards that depend on a stalled provider may show a refresh state.
