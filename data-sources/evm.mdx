---
title: "EVM wallets and positions"
description: "Zerion powers everything EVM in Retina."
---

**Zerion** is the data provider for EVM wallets across every chain Zerion supports. Pasting an EVM address in [setup](/getting-started/quickstart) (or adding one later) causes Retina to call Zerion for that address and normalize the result into the [position model](/concepts/position-model).

What Zerion surfaces, and Retina ingests:

- Spot token balances per chain
- Protocol positions (staking, LPs, vaults, deposits)
- Position metadata used downstream for APY, maturity, and asset class

When Zerion does not return an APY for a position, Retina falls back to DeFiLlama. See [Yield data](/data-sources/yield).
